# Centro Ferretero El Pico — Tienda web

Next.js (App Router) + TypeScript + Tailwind CSS v4.

```bash
cp .env.example .env.local   # opcional: sin CATALOGO_API_URL se usan los datos de lib/mock/
npm install
npm run dev                   # http://localhost:3000
```

Antes de cada commit: `npm run lint` y `npm run build` sin errores.
